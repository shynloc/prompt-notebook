# ImageHub 2.5 release verification

Release: 1.8.0. Database migration: 0017 (additive metadata column; expanded quality and asset-role checks).

## Review

- UI, API preflight and provider serialization share model capability validation. Official 2.5 variants/snapshots and explicit third-party family overrides are distinguished from unverified aliases.
- No size substitution, credentials, provider endpoints or account defaults are embedded in the new workbench. A default-model selection is resolved to a concrete profile for each submitted request.
- Output metadata is allowlisted and bounded. History and saved notes distinguish requested dimensions from actual image dimensions.
- Mask dimensions, PNG alpha, per-file and aggregate sizes are checked before queueing. Browser-native canvas tests verify actual PNG output on desktop/mobile. EXIF rotation is normalized before submitting references to match mask coordinates; fingerprints retain original request bytes.
- Ambiguous provider network failures, interrupted result bodies, completed generations with storage failures and stale running tasks cannot automatically regenerate. Explicit retryable provider responses retain bounded retries.
- Atomic cancellation cannot overwrite succeeded/failed terminal states. Interrupted stale cancellation requests become removable terminal records. Worker cancellation propagates to the local provider connection; upstream cancellation/charges cannot be guaranteed.
- Generated files may be up to 32 MiB; reference/mask inputs remain 10 MiB each and multipart requests 44 MiB total. Media downloads retain validated public DNS pinning and owner isolation.

## Completed local checks

- PostgreSQL migration applied successfully to the local test database.
- Full Vitest suite: 62 files / 324 tests pass, including authenticated database integration tests and cancellation/storage/mask edge cases.
- Focused provider/capability tests: 43 pass on patched Vitest 4.1.12.
- Chrome extension: 4 files / 7 tests pass; Vite 7.3.7 build passes with coordinated 1.8.0 versioning.
- Full Playwright suite: 38 pass, including genuine canvas strokes/multipart masks at 1440 and 390 pixels, downloads, note saving, reverse prompts, settings, sharing and existing notebook flows.
- Desktop/mobile workbench and mask screenshots visually reviewed; no horizontal overflow or obstructed confirmation controls.
- Production web build, generation-worker build, TypeScript and release-configuration checks pass.
- ESLint: zero errors; twelve existing full-page-navigation warnings outside this release's modified components.
- Production dependency audit: zero vulnerabilities. The full development audit retains the previously documented unpatched braces advisory through Next's lint tooling; do not use the proposed incompatible Next-lint downgrade.

Automated providers use deterministic fixtures and do not spend user credits. These checks verify request/response contracts and application workflows, not a particular third-party provider's advertised capability or visual output quality.
