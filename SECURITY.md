# Security policy

Please do not disclose a suspected vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository and include the affected version, reproduction steps, impact and proposed mitigation. Do not include real user data or destructive proof-of-concept actions.

The maintained version is the latest GitHub Release and current `main`. Self-hosters are responsible for HTTPS, operating-system and container updates, secret rotation, SMTP security, database and image-host backups, and access control for deployment directories.
